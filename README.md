# La Table de Cat

Planning de repas, recettes, courses, suivi du poids et réintroduction alimentaire (un seul fichier `index.html`, sans serveur).
Les données restent dans le navigateur de chaque appareil (export / import dans Réglages).

`index.html` est généré par `python3 build/build_cat.py` à partir des sources de `build/`. Voir `CLAUDE.md` pour le mode d'emploi.
